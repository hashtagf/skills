# Photographs for previews

Open-collection photographs (Wikimedia Commons; CC0, public domain, CC BY or CC BY-SA) used by `scripts/composition_preview.js` so previews show real imagery, not palette-drawn shapes. Credits and licence for each file are in `credits.json`; a page that ships one of these must credit it (see `references/visual-assets.md` §2b). They are stand-ins for a client's own photographs.
