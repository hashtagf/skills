finished; cookie banners present. Values describe that one surface/state only —

## Method

Script per page: computed styles for body, first visible h1/h2/h3/p, first two
filled links/buttons; frequency of font-size (text-bearing nodes), font-family,
color, background, border-radius, box-shadow, gap, 1px borders; padding-top of
full-width blocks taller than 300px; centered max-width containers. Up to 3,000
visible nodes per page. Re-run before relying on any single value.
