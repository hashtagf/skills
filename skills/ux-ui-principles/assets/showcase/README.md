# Open Design showcase — catalog

Our own notes on the 98 entries of <https://open-design.ai/showcase/?type=all> (fetched 2026-11-05), grouped into 65 distinct captures (many entries reuse one picture). The pictures and the site's own text are a **local study set**: `python3 scripts/showcase_fetch.py` downloads them into `assets/showcase/img/` (git-ignored, because each entry's licence covers the plugin, not every depicted asset). This file and `catalog.json` are our summaries with links; they do not copy the site's text.

**How to use:** filter by kind, open the `template` rows of your kind (picture in `assets/showcase/img/<slug>.jpg` or the link), then start from the named composition in `scripts/compositions.js`. Never reuse a showcase page's names, copy or imagery in client work.
